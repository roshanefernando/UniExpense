# 💰 UniExpense

**UniExpense** is a simple and user-friendly Android expense management application designed to help students track their daily finances, manage expenses, monitor their balance, and maintain better control over their spending.

The application focuses on providing essential financial management features through a clean and easy-to-use interface.

---

## ✨ Features

* 💵 **Income Management**

  * Add income records
  * Track available income

* 💸 **Expense Management**

  * Add and manage expenses
  * Categorize expenses
  * Edit and delete transactions

* ⚖️ **Balance Tracking**

  * Monitor current balance
  * View income and expense differences

* 📅 **Date-Based Transactions**

  * Record transactions with dates
  * Keep track of financial activity

* 📊 **Expense Statistics**

  * View spending statistics
  * Analyze expenses by category

* 🎯 **Monthly Budget**

  * Set a monthly spending budget
  * Monitor spending against the budget

## 📱 Application Overview

UniExpense was developed with simplicity and usability in mind. The application provides students with a convenient way to record their income and expenses without the complexity of traditional financial management applications.

The project also demonstrates practical Android development concepts including:

* UI design with Jetpack Compose
* State management
* User input handling
* Navigation between screens
* Form validation
* List management
* Financial calculations
* Category-based data organization

## 🎯 Project Goals

The main goals of UniExpense are to:

1. Help students understand their spending habits.
2. Make daily expense tracking simple.
3. Provide an easy way to monitor income and balance.
4. Encourage better personal financial management.
5. Practice real-world Android application development.
